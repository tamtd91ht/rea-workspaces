# Projects

One directory per project, named `YYYYMMDD-short-name`. Contents are not
tracked by the workspace repository; a project may have its own repository.

- Create: `node scripts/new-project.mjs --help` or `/rea-project-init` in Claude Code.
- List: `node scripts/check.mjs projects`.
- Lifecycle and layout: [../docs/project-lifecycle.md](../docs/project-lifecycle.md).

Do not create projects by copying another project or the template by hand.
