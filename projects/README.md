# Dự án

Mỗi dự án một thư mục, đặt tên `YYYYMMDD-ten-ngan`. Nội dung không được repo
workspace theo dõi; mỗi dự án có thể có repo riêng.

- Tạo: `node scripts/new-project.mjs --help` hoặc `/rea-project-init` trong Claude Code.
- Liệt kê: `node scripts/check.mjs projects`.
- Vòng đời và cấu trúc: [../docs/project-lifecycle.md](../docs/project-lifecycle.md).

Không tạo dự án bằng cách sao chép dự án khác hoặc chép template bằng tay.
